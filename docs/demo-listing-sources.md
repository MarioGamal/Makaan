# Demo listing market sources

The 20 market-shaped fixtures added on 2026-09-18 use publicly visible asking
prices, areas, bedroom counts, and bathroom counts as reference points. They are
not republished listings. Makaan uses original fixture titles/descriptions,
approximate coordinates, non-routable demo sellers, and locally owned demo
media. Broker names, phone numbers, exact addresses, and third-party photos are
not imported.
